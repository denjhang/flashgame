# 武器类型详解——为什么雷达是游戏里最鸡肋的设定

根据反编译提取的 `unitsMissions` 数组和 SWF 原始资源中的武器定义，整理出游戏中全部 26 种武器（25 种有效 + null 占位符），逐一分析属性、价格，说明为什么雷达是游戏中最鸡肋的设定。另有 Su-37 空袭支援是剧情支援单位，不计入武器列表。

---

## 一、武器类型总表（从 `typeData` 提取）

`typeData[type]` 数组的 6 个元素含义（从 `DefineSprite_174` 第 123-134 行确认）：

| 索引 | 变量名 | 含义 | 说明 |
|------|--------|------|------|
| 0 | `rotateSpeed` | 射速因子 | 数值越小射速越快，乘以 `_root.fpsc` 计算旋转速度 |
| 1 | `distanceOfFire` | 射程 | 攻击范围，像素单位 |
| 2 | `numberOfRequestForPermission` | 威力/伤害 | 经过 `Math.floor(typeData[type][2] / fpsc)` 计算为实际伤害 |
| 3 | `nCanons` | 炮管数量/连发数 | 一次发射几发炮弹 |
| 4 | `puissance` | 生命值（HP） | 武器的耐久 |
| 5 | `impact` | 冲击/溅射伤害 | 范围伤害值 |

## 三、为什么雷达是鸡肋——根本没用

### 1. 游戏没有战争迷雾，全图透视
**这是最核心的问题。** 从游戏一开始，你就能看到全地图上的所有敌人。没有战争迷雾，没有视野限制——你不需要任何雷达就能直接看到最上面的敌人。这一点完全不同于《红色警戒》（红警有战争迷雾，雷达塔只能显示小地图上的敌人位置）。

### 2. 雷达的射程/视野没有任何意义
- 雷达的射程属性是 `distanceOfFire = 1200`（玩家雷达）和 `1500`（敌方雷达车），但这只是"视野范围"，不是武器射程。
- 游戏本身就全图可见，1200 像素的"视野范围"和你原本看到的 10000 像素范围比简直微不足道——你本来就看得见 10000 像素范围以外的敌人。
- 即使雷达让你看到 1200 范围内的敌人，你也没有射程那么远的武器能打得到（最高射程武器 pluton 也只有 10000，MLRS 只有 1300）。
- 雷达不能帮你看到任何你看不到的东西，因为它只是扩大了一个你根本不需要扩大的视野。

### 3. 雷达不是武器，没有攻击属性
从 `typeData` 定义表可以确认：
- `radar` 的属性：`(0, 1200, 0, 0, 0, 0)`——攻击力 0、影响范围 0、射速 0、生命值 0
- `radarMobile` 的属性：`(0, 1500, 0, 0, 0, 0)`——同样是零属性
- 没有任何攻击能力，不能伤害任何敌人
- 它只是一个视野辅助单位，而且这个辅助没有任何意义，因为游戏本来就全图透视

### 4. 雷达的"视野"设计是废案
- 如果游戏参考红警设计了战争迷雾，雷达确实有用——它能扩大你的视野范围，让你看到炮塔射程之外的敌人，配合高射程武器（MLRS、pluton）才能发挥价值。
- 但游戏没有战争迷雾，雷达就成了纯粹的设计废案——一个被设计出来但毫无意义的单位。
- 雷达的射程（1200/1500）比你的武器射程（最高 1300）大不了多少，而且你根本不需要看到这么远——全图透视意味着你从一开始就能直接看到 10000 像素外的敌人。

### 5. 雷达是纯粹的"肉盾"
- 敌人会打它，它打不了任何人（攻击力 0）
- 雷达没有生命值（`puissance = 0`），被摧毁了也无所谓（反正不提供视野，游戏本来就全图透视）
- 建造雷达 = 浪费一个可建塔位 = 少建一个可以杀敌的炮塔

### 6. 雷达的价格也不便宜
- 基础价格 220，升级价格 250，虽然便宜但也是个浪费——你拿这些钱可以造 m60（120）或者 gatling（200）来杀敌，结果造个完全不能攻击的雷达。
- 对比 crotale 导弹（220/1000），它既有攻击又能打空对地，而雷达什么都做不了。

**总结：雷达在这个游戏里完全没用。游戏从一开始就全图透视，不需要任何雷达就能看到所有敌人。雷达没有战争迷雾、没有视野限制、没有攻击能力、没有生命值，纯粹是个摆设，连肉盾都算不上——因为它根本不值钱，敌人甚至懒得打它。**
