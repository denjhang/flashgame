## 0. 全局约定

- 定点数: 位置/速度类 256=1.0 (`>>8`); 正弦表 `(ci)` 32768=1.0 (`>>15`); 天气色彩 1024=1.0。
- 正弦表 `(M():4122)`: `ci[360]` 积分构建, `j(deg)=sin`, `k(deg)=j(deg-90)=` **−cos**。
- 游戏时钟 `cg` 毫秒累计; 局内时距一律 `cg − aE`。
- 屏幕坐标: `(E,F)`=屏宽高; 塔世界锚点 `(aV,aW)`; 3D→2D 投影
  `x = aT + (32·(x−aV)>>8)`, `y = aU − (32·(y−aW)>>8)` (缩放 32/256=1/8)。
- 状态字 `e` (gameState): 3=城市入口 / 4=快速入口 / 5=城市局中 / 6=快速局中。
- 快速局入口 `(n():3111-3122)`: `f.a(12)==4` → **bl(塔色索引)=4**, `bg=k[3]=40`,
  `K()` 塔数组初始化, `h()` 读 quickModeRS 续档。

## 1. 帧循环 (每 tick, `:1697-1719`)

cM 累计真实 dt, **≥25ms 才步进一次**, 整段 cM 作为 delta 传入:

```
z()      相机跟随 (:1765)
u(cM)    天气导演 (:2260)
E()      背景鸟群 (:2625)
p(cM)    摆钩 (:1791)
s(cM)    块物理+命中结算 (:1852)
q(cM)    塔摇摆 (:1817)
A()      摇摆投影到各层 (:1999 起)
B()      惊慌人群 (:2160)
连击计时: bA>0 → bA −= cM + (bz−1)·cM/6; ≤0 → H() 结算银行
          (bA≤0 后继续衰减到 −2000 为 HUD 显示窗)
```

## 2. 塔数据结构

| 结构 | 语义 |
|---|---|
| `bs` 层数 / `bx,by` 可见窗 | 窗=max(0,bs−5)..min(4,bs−1), 永远只渲染 5 层 |
| `aF[20]` byte | **层落点偏移环缓冲** (bs%20): 完美=0, 否则=本层偏差 byte。摇晃/惊慌/扣分全从它取档 |
| `bi[5]/bj[5]` | 层中心 x / 层顶 y (世界坐标) |
| `bh[5]` | 层渲染 x (A() 摇摆投影输出, −999/−888 特殊标记) |
| `cF[5]` | 层渲染倾斜 (落地时=±偏差/4, **随机翻号**, 持久) |
| `aw[0..4]` | 块状态机: 1=挂钩随行 2=玩家投放 3=屋顶落空收回 4=已消 5=撞塔掷飞 6=提钩上升 7=砸地横躺 |
| `bm/bn/bo` | 塔倾斜累计 (左右) / 地基偏差 |

`K()` 初始化 (`:161 附近`): `bj[0]=−256` (地面层顶), `aJ=2432` 吊钩基线, `aH=1664` 提钩顶。

## 3. 摆钩运动学 (`p():1791-1815` + 参数插值 `z(int):2944-2996`)

```
aP += dt                                  // 相位累子 (ms 域)
提钩态 aw[0]==6: aH += 2dt/3, 顶到 1664 (bk==1 屋顶期 1408) → aw[0]=1 挂钩态
aK = cQ·k(200·aP/cP % 360) >> 15          // 钩 x = cQ·(−cosθ), θ=200aP/cP
aL = aJ − cO − aH − (cR·j(θ) >> 15)       // 钩 y = 基线 −缆长 −提升 − cR·sinθ
挂钩态: aB[0]=(aK−aN)·256/dt, aC[0]=(aL−aO)·256/dt   // 本帧钩速 (投放惯性来源)
```

参数表 (`static :4346-48`): `aQ={213,256,298,341,384}` 横摆幅 / `aR={85,106,128,149,170}` 纵摆幅 /
`aS={1670,1700,1650,1600,1550,1500,1450}` 周期基准。每次层数变更 `z(±1)` 重插值:

- **快速局** (e≠5, bl=4): `cQ=min(aQ[4], aQ[0]+bs·(aQ[4]−aQ[0])/60)` — **60 层才到满幅**;
  `cR` 同式 (aR); bs<100: `cP=max(aS[6], aS[0]−bs·(aS[0]−aS[6])/100)`,
  `cO=−min(128, bs·256/200)`; bs≥100: `cP=aS[5]−(bs−100)·100/150`,
  `cO=−min(256, 128+(bs−100)·256/300)`。相位守恒 `aP=aP·cP/旧cP`。
- 城市局 (e==5): `cQ=min(aQ[bl], aQ[1]+bs·Δ/(bg>>1))` … `cO=−min(128|256, …)` (另一套, 快速局不走)。

投放 (`J():3716-3727`): FIRE 且 `aw[0]==1 && aW==aX` (挂钩态+相机到位) →
`aw[0]=2, aD[0]=aL` (抛物线起点=当前钩高), `aE=cg`。

## 4. 块物理 (`s():1852-1994`)

- **aw=2/5 抛物线** (投放/撞塔掷飞): 令 t=cg−aE−cl[i];
  `aA = aD + aC·t/256 − t²/n10` (n10=200, 屋顶期 400), 每帧下降钳 ≤256;
  `az += aB·dt/512` (水平惯性 = 投放时钩速连续作用);
  x/旋转 500ms 线性收敛 `ax→ay`, `cG→cH`。
- **aw=2 出屏底** (`aA < aW−be/2`): 记 `cm` (出屏小人 300ms), `aw=4`;
  若是玩家投放块: 银行结清 → **A(1) 扣命**。
- **aw=2 落到判定高度 → G()** (见 §5)。
- **aw=3 屋顶落空收回**: `aA += 15·(cg−aE)>>8` 升回 `aJ−512` → 提钩复位 (aw=6)。
- **aw=7 砸地横躺**: `aE+cl[i]` 期满 → 落到层顶, aw=5, `t(bs)` 惊慌, `z(−1)`。
- 帧尾: `aw[0]==4 && aE<cg−400 && 无坠块` → 提钩复位 (aH=1664, aw=1, dD=clamp(4,bs−1), cP=aS[1])。

## 5. 命中判定 (`F():2776` + `G():2790-2918`) — 核心

`F()`: 游标 `dD` 自可见窗顶沿 `bj[层]` 下行, 块心 `(az[0],aA[0])` 落入
层顶±256 且层中心 x±256 → 返回层号, 否则 −1。

`G()` 分支 (n4=命中层, n3=az[0]−bi[n4] 横向偏差, n2=|n3|):

1. **屋顶落空** (bk==1 且未命中顶层): `aw=3` 收回 + `A(1)` 扣命, return false。
2. **未命中任何层** (n4==−1): return false, 块继续 aw=2 坠出屏 → §4 出屏扣命。
3. **地基** (bs==0): 音效 800, aw=4, `bo=bn=bm=n3` (地基偏差直灌倾斜), `z(1)`, 无人口。
4. **命中顶层** (n4==min(4,bs−1)):
   - |n3|≤127 → **落住**;
   - ≥128 → **过界**: 银行结清; 屋顶期→收回+扣命; 否则 aw=5 弹飞 +
     `d(方向, −1)` **错位倾塌检查** + 弹飞速度 (aB=±500, ay=∓45, cH=±60, aC=50)。
5. **命中低层** (n4<顶层): `d(−方向, min(4,bs−1)−n4+1)` **计数连锁** + 银行结清 + aw=5 弹飞。

**落住结算** (分支 4 的 |n3|≤127):
- `bz==0 → bB=0`; `bA>0 → ++bz` (连击=计时器存活期内的连续落住数, 完美与否都计);
  `bC=max(bC,bz)`。
- `bm += n3` (倾斜累计)。
- n2<25 **完美**: `aF[bs%20]=0`, `bA=6000` (bk≠1), `c(4,bs+1)` 4 人, `ch=cg`;
  否则 `aF[bs%20]=(byte)n3`, `c(3|2|1, bs+1)` 按 50/80 档。
- `cF` 数组下移一格, `cF[n4]=±n3/4` (随机翻号, 持久倾斜)。
- `z(1)` 层数+1 (触发 §3 参数重插值 + 相机)。
- **屋顶块** (bk==1): 人口 `bB=(128−n2)·bl/2` (奖杯 bD) 或 `(128−n2)/(5−bl)`,
  `y(bB)`, bA=0。与 Flash roof 公式同源已证。

## 6. 人口/连击银行 (`y():2920` / `H():2935` / `c():2074`)

```
y(n):  n>0: bA>0 → bB += bz·(2+bs/10·2)   // 银行加成
            bt += bs/10 + n               // 实得 = 层数/10 + 增量
       n<0: bt −= bs/10 − n               // 扣分同公式取负
H():   bt += bB; bz=0; bA=0               // 计时器归零瞬间结清
连击计时 (帧循环): bA −= dt·(1+(bz−1)/6)   // 连击越高流逝越快
完美: bA=6000 固定; 非完美落住: 不调表
```

`c(n, 层号)`: 先 `y(n)` 结算人口, 再生成 **n/2 个**惊慌小人 (8 槽, 屏幕两侧出生, y=屏下方+rand768)。

## 7. 机会与结束 (`A(int):2998`)

`A(1)`: `cN=cg`, 音效 800, `bb/bc` 记变更, `ba−−`; `ba==0 && !HoF` → **bk=2 倒塌态**
(屋顶块结算面板 → jingle 84/85 → 快速局 HoF 提交 → 退出存档)。

## 8. 塔摇摆 (`q():1817` + `z(int)` + `A()` 投影)

```
q(dt): bw=(bw+dt)%3600; cS=k(bw/10)=−cos(bw/10°); bu→0 收敛 (bk==2 时每 tick ±1)
       br = −(cS·bv)/10000            // 塔倾角 (消费单位: A()/3D 旋转, 见偏差#6)
z(int): bv = min(bs/2+|bm|/20, bs·(bs/2+|bm|/20)/6)      // 摆幅
        dF = 5 层窗 |aF| 均值 (clamp bs·dF/20 ≤ 100)
A():    塔倾 (bn+br) 逐层投影到 bh[](渲染 x), 顶块放置后 100-800ms 三段缓动
```

周期 3600ms (bw 0..3600 → 角 0..360°)。

## 9. 惊慌人群 (`t():2099` / `B():2160`)

`t(层)`: 档位 = |aF[层%20]| <25→4 / <50→3 / <80→2 / else 1, **>>1** 为抛飞数 (2/1/1/0);
该层现有小人 → 坠态 3 (速度=±距/500); 不足从空槽取 → 掷飞态 4。
`B()`: 1 原地跳(bF/bG 跳弧表, 2000ms)→2 走向块缘(bi±64)→5 站立 500ms→释放;
4 掷飞 300ms→3 坠落; 出屏回收。绘制 `k(Graphics)` 3D→2D 投影, 两款小人 aa/ab (id12/13)。

## 10. 相机 (`z():1765` / `o(int):1786`)

`o(Δ)`: `aY=cg`, `aX = bs>1 ? aX+Δ : 512` (每层抬一档, 地基回地面)。
`z()`: aW 向 aX 以 `(cg−aY−500)·256/500` 步长趋近 (500ms 缓动);
到位后 `aJ=aW+1792+128` 吊钩基线跟随; `cg−cN<800` (扣命后 800ms) 相机加随机抖动 ±32。
**投放门槛: aW==aX** (相机没到位不能放块)。
