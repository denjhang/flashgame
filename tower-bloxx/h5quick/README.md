## 运行

- 本地：`cd h5quick && python -m http.server 8210` → `http://127.0.0.1:8210/`
- 操作：点击/空格/回车 = 落块（松开放块）。3 次机会，无尽盖楼。
- 存档：退出自动存 `localStorage["twrblx_quickRS"]`（House g:443/h:618 语义），结算后清除。

## 渲染管线（2026-10-02 重写, 按反混淆原文）

- **相机**：`setPerspective(55·1.2333, 0.825, 10, 10000)`（n.java setFov/setupViewport 原式，
  fovY=67.8°、aspect=0.825——非屏比 0.75）；相机位 `(塔x, aW, cI)` 朝 −z
- **cI 迭代**：y():1436 原式——投影世界点 (0,−384,128) 至屏心下 ≤48px，cI≈2128
  （注意 three.js `Vector3.project()` 已含透视除法，Vector3 无 w 分量）
- **网格**：零缩放原始坐标（m3g bias/scale 已由 GLB 解码, uid13 块=256³）；
  节点名 `mesh<uid+250>`（GLTFLoader 拆子网格带 _N 后缀, 查找需兼容）
- **uid 表**：标准块=13/地面=9/吊臂=8/缆=7（House:1259-1277, bl=4）
- **分层**：天空/环境/HUD 全 2D 画布；WebGL 只画 3D（alpha 透明, 对号 J2ME"3D 只清深度"）
- 已修回归：aJ=aW+1920 吊钩基线只在相机移动帧更新（z():1779）——漏掉会导致钩子低于塔顶、落块砸低层连锁
- 实机验证：内置浏览器连放 6 块至 7 层, 连击条/命数/人口/相机跟随全部正常（截图核对）
