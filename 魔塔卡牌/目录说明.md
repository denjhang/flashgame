# 魔塔卡牌 — 目录结构说明

> 原作：刘天健，2010 年小学五年级创拍手游戏，2011 初一做 Flash 0.1 版，
> 2020-02 发布 AS3 版 V0.1.6，2026-10 完成 HTML5 移植。
> 完整考证与玩法规格见 `魔塔卡牌-玩法研究.md`（权威文档）。

## 一手成果（git 入库）

| 目录/文件 | 说明 |
|---|---|
| `h5_port/` | **HTML5 移植版**（index.html + main.js + assets 手绘卡牌） |
| `h5_port/card-straightener.html` | 卡片拉直工具（角点+边框点、实时透视预览、放大镜） |
| `卡牌抠图.py` | 从拍摄照片批量抠出卡牌的脚本 |
| `素材全集2026拍摄/` | 2026 年重拍的卡牌原件照片（4 角色出招表纸片+折纸包）|
| `素材全集2026拍摄/抠图输出/` | 上述照片自动抠图结果（261 张）|
| `魔塔卡牌-玩法研究.md` | 玩法/数值/历史/素材考证权威文档 |
| `目录说明.md` | 本文件 |

## 原始资料（作者旧文件，git 忽略）

`考证产物/` — swf_export（62 帧渲染图/文本/脚本导出）、extracted（fla 解包）、
fla_media_*（fla 内嵌图对比）、swf_test_export 等。
